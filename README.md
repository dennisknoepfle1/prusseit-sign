# Prusseit Sign

iPad-Web-App der Autowelt Prusseit GmbH, mit der Kunden Kaufverträge (PDF) elektronisch und beweissicher unterschreiben.

- `index.html`, `manifest.webmanifest`, `sw.js`, Icons: die App (läuft über GitHub Pages, kein Build)
- `supabase/migrations/`: Datenbankschema (Supabase-Projekt „Prusseit Sign“, eu-central-1)
- `prototype/`: erster Prototyp ohne Server

Auf dem iPad: Seite in Safari öffnen → Teilen → „Zum Home-Bildschirm“.
